# 杠杆调整 · 币安 U 本位合约仓位面板

单文件网页（`杠杆调整.html`），双击即可在浏览器打开，无需安装、无需服务器。所有代码内联，API Key / Secret 只保存在本机浏览器的 localStorage，不经过任何第三方。

## 功能

- **点击「获取」**：读取币安 U 本位合约当前仓位，列出仓位名称、多空方向、仓位数量、杠杆倍数
- **仓位数量按 USDT**：持仓量 × 标记价格，千分位保留两位小数，并按金额从大到小排序
- **分页**：每页 15 个交易对
- **搜索筛选**：表头输入框按交易对名称实时过滤（不区分大小写，支持部分匹配）
- **点击杠杆倍数**可弹窗修改该合约杠杆，调用 `POST /fapi/v1/leverage`，上限 150
- **API 密钥设置**在右上角「设置」独立页面里填写，保存后回到主界面

## 使用

1. 右上角「设置」填入 API Key / Secret 并保存
2. 密钥需要有「允许合约」权限（只读 Key 只能查看仓位，**改杠杆必须开通合约交易权限**）
3. 点「获取」读取仓位；点杠杆倍数修改杠杆

需要本机能访问 `fapi.binance.com`（中国大陆网络请先开启代理），否则会提示请求超时。

## 实现要点

- 纯原生 JS 实现 SHA-256 / HMAC-SHA256，不依赖 `crypto.subtle`，`file://` 直接打开也能签名
- 签名请求统一走 `signedRequest()`，GET / POST 共用；遇到 `-1021`（时间偏差）自动重新对时并重试一次
- 视图用 hash 路由切换（`#/` 主界面、`#/settings` 设置页）

## 安全

密钥只存在本机浏览器 localStorage，不写入代码、不上传服务器。换电脑或清除浏览器数据后需要重新填写。
